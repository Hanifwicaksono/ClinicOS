# Backlog pengembangan yang diprioritaskan

Tanggal audit: **14 November 2026**. Audit produk read-only; tidak ada implementasi/perbaikan. Fakta source/UI dipisahkan dari inferensi kebutuhan dan rekomendasi. Semua UI menggunakan data dummy pada SQLite terisolasi. 

**P0: 0 dibuktikan; P1: 9 item; P2: 9 item; P3: 0 gap kanonis wajib.** Kiosk/custom permission/branches/Edge adalah kandidat opsional terpisah, bukan item wajib tambahan. Tidak ada estimasi effort hari tanpa validasi tim. S/M/L/XL relatif terhadap pola domain sekarang, bukan komitmen jadwal.

P1 = menutup tugas inti/recovery atau kebutuhan bersyarat scope. PG-05/07 khususnya **bukan otomatis MVP wajib** hanya karena berlabel P1: jadi prioritas saat klinik target memerlukan penyelesaian kas/dokumen. PG-14 berlaku jika data terkait ditemukan. Tidak ada bukti audit untuk mengklaim pelayanan saat ini selalu terhenti atau membahayakan pasien.

Audit ini tidak memberi izin implementasi, commit atau deploy.
